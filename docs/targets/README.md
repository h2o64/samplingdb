# Targets

## Two splits

`train_samples()` is cheap and deliberately biased, so a sampler may train on it. Every one is
generated locally by a documented recipe from a fixed starting point and a fixed seed, and cached;
the recipe is stated in the target's `generate_train_samples` docstring. For most targets it is a
classical sampler that is locally correct and globally short.

`test_samples()` is the reference a sampler is scored against. It is exact draws where those are
free, and otherwise a reference set generated by this library (see
[Reference sets](../reference-sets.md)). Published reference sets stay available through
`load_split()` or `released_samples()`, for comparisons with numbers reported against them.

Both splits hold 100 000 samples by default and take any `n`. A larger train split is regenerated
under its own cache entry; a test split returns its first `n` rows, which span every chain of the
run that generated it.

## Truth tiers

`truth_tier` says how the reference set exists.

| Tier | Family | Reference |
| --- | --- | --- |
| 0 | [Synthetic](synthetic.md) | exact draws |
| 1 | [Particle systems](particles.md) | this library's parallel tempering |
| 2 | [Bayesian posteriors](posteriors.md) | this library's Stan runs |
| 3 | [Peptides](peptides.md) | this library's replica-exchange molecular dynamics |
| 4 | [Glass formers](glasses.md) | this library's swap Monte Carlo or parallel tempering |

## Not in the catalog

| Target | Reason |
| --- | --- |
| DW-2 | no reference split was ever published for it |
| The IPL glass formers | dropped |
| Cu-Zr, Cr-Co-Ni and the larger alloys of Cheng et al. 2026 | each sits at its own glass transition, so no reference ensemble exists to score against |
| The other alanine-dipeptide force fields (ff96 + OBC1, GFN2-xTB, ff99SB-ILDN + ff99-OBC) | one alanine dipeptide is enough, and the SBG one is the catalogued one |
| The many-peptides transferability family | a family over molecules is out of scope |
| NICE flows on MNIST (Digits, Fashion) | a trained-model artifact rather than a density; deferred |
| Adjoint-sampling / GEOM drug-like molecules | a different kind of energy; deferred |
| phi^4 / stochastic Allen-Cahn lattice | deferred |
| Crystals (mW ice, LJ FCC/HCP, silicon) | needs free-energy machinery of its own; deferred |
| Ising, Potts, XY | a discrete state space has no score |
